# 🎙️ TalkDraft

TalkDraft is a Kotlin Multiplatform (KMP) mobile application built with **Clean Architecture**, focused on
**local-first, privacy-focused AI transcription and note-taking**.

Android is the primary platform, with seamless iOS support designed into the core architecture without polluting shared
business logic with platform-specific code.

## 🌟 Core Product Principles

TalkDraft prioritizes:

1. 🔒 **Privacy**: User data stays local unless cloud functionality explicitly requires otherwise.
2. 📶 **Offline Functionality**: Core transcription and note-taking work entirely offline without requiring
   authentication or network connectivity.
3. 📱 **Simple UX**: Minimal unnecessary complexity, delivering clear product value with an intuitive user experience.
